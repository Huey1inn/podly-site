# podly-site

Public support and privacy pages for the podly iOS app.

- `index.html` — support and FAQ
- `privacy.html` — privacy policy
- `assets/` — icon and stylesheet

## Publishing

Enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` / root).
The site is then served at:

- https://huey1inn.github.io/podly-site/
- https://huey1inn.github.io/podly-site/privacy.html

Use those URLs in App Store Connect for Support URL and Privacy Policy URL. The
Marketing URL is optional.
